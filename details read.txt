Prithu Training App - Detailed Overview
=======================================

1) Purpose of the App
---------------------
The Prithu Training App is a web-based training platform for delivering structured learning content to users.
It organizes training by domain sections (for example Construction, Plumbing, Paint, and Wellness) and provides
video-first learning with secure access for protected content.


2) Core Functionalities
-----------------------
- Dynamic content rendering from content.json:
  Home page headings, navigation links, branding assets, feature cards, and training metadata are configured from JSON.

- Category-based training discovery:
  Users start on the home page and click feature cards to open the corresponding section on the Training Videos page.

- Section-wise video playback:
  Training videos are grouped and shown by section with sequence ordering and per-section sequence quick links.

- Interactive video viewing:
  Videos are displayed in card layout and can be opened in a large modal view with close controls.

- Authentication-aware access:
  UI login state is managed using Microsoft identity (MSAL). Signed-in users can access protected blob-based videos.

- Secure media URL generation:
  Protected videos use short-lived SAS URLs generated by an Azure Function after token validation.


3) Frontend Architecture
------------------------
- index.html
  Main landing page with hero section, feature cards, and navigation.

- trainingVideos.html
  Training section page that renders categorized videos, sequence navigation, and enhanced playback UI.

- content.js
  Loads content.json, updates shared UI elements, and emits contentReady events.

- auth.js
  Handles MSAL sign-in/sign-out behavior and updates auth-related UI state.

- script.js
  Handles common client-side interactions such as navbar behavior, smooth scrolling, and mobile menu toggle.

- training-videos.js
  Renders training sections/videos, resolves secure video URLs, and manages video modal interactions.

- style.css
  Global styles for layout, cards, navbar, hero, responsive behavior, and footer presentation.


4) Backend / Cloud Components
-----------------------------
- Azure Function App (SiteTrainingAppVideos)
  Hosts backend function endpoints for secure operations.

- GenerateVideoSas function
  HTTP-triggered function that:
  1. Accepts a target video file name
  2. Validates Azure AD bearer token
  3. Generates a short-lived read SAS URL for the target blob
  4. Returns JSON containing the SAS URL

- Azure Blob Storage
  Stores training video assets in the configured training container.


5) Security Model
-----------------
- User authentication:
  Users sign in via Microsoft identity; auth state is reflected in the UI.

- API authorization:
  Backend validates Azure AD token before issuing SAS.

- Least-lifetime URL access:
  SAS tokens are short-lived, reducing long-term exposure risk.

- Separation of concerns:
  Frontend does not directly hold storage account credentials.
  Secure URL generation is done server-side in the function.


6) Process Flow (End-to-End)
----------------------------
1. User opens home page.
2. Frontend loads content.json and renders navigation, hero, and feature cards.
3. User signs in (if not already signed in).
4. User clicks a training card (for example Construction).
5. App routes to trainingVideos.html with section hash.
6. Training page renders section/video cards and aligns to the selected section.
7. For protected blob videos, frontend requests GenerateVideoSas with bearer token.
8. Function validates token, creates SAS URL, and returns it.
9. Frontend binds returned SAS URL to video source and user plays the video.


7) Configuration-Driven Behavior
--------------------------------
- content.json acts as primary content/config source for:
  branding, navigation, hero text, section metadata, video definitions, and footer content.

- Cloud settings (Function App environment variables) control:
  storage account references, target container, and Azure AD validation values.


8) Deployment and Operations
----------------------------
- Static web assets are served via GitHub Pages from the main branch.
- Backend function code is deployed to Azure Function App.
- CORS is configured to allow the frontend origin to call function endpoints.
- Codebase is split to keep function project files separate from website files.


9) Current UX Enhancements Implemented
--------------------------------------
- Card-like training video layout with responsive multi-column grid.
- Sequence quick-link bar per section.
- Video modal expansion with close button and Esc support.
- Navbar consistency across pages, including mobile menu improvements.
- Footer customization and external maintenance attribution link.
